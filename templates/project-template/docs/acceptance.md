# 当前版本验收清单

## A. 规范完整性

- [ ] 根级规范文件存在且非空。
- [ ] `docs/INDEX.md`、`product-spec.md`、`architecture.md`、`implementation-plan.md`、`acceptance.md` 存在。
- [ ] 至少有一条 ADR 记录本次架构选择。

## B. 边界

- [ ] 文档明确各层职责与依赖方向。
- [ ] 文档明确禁止凭据进入仓库。
- [ ] 文档明确对外动作需要用户当次授权。
- [ ] 文档明确外部数据只读引用。

## C. 可验证性

- [ ] `npm run verify` 退出码为 0。
- [ ] 删除一个必需文件后，验证命令退出码非 0。
- [ ] 加入明显凭据模式后，验证命令退出码非 0。
- [ ] Markdown 结构问题（空文件、无标题、代码围栏不配对）能阻断验证。

## D. 交付纪律

- [ ] 未声称完成任何未经用户确认的对外动作。
- [ ] 没有新增未授权的登录、发布或付费调用。
- [ ] 原始目录与外部真源未被搬迁或改写。

## E. 版本控制

- [ ] 仓库已纳入版本控制，`.gitignore` 存在。
- [ ] 提交内容中不含依赖环境、运行时日志、生成产物或凭据。
- [ ] 被忽略的重要产物在索引中有路径指针和校验值。
