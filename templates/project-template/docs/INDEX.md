# 文档索引

| 文档 | 用途 | 何时阅读 |
|---|---|---|
| `product-spec.md` | 目标、用户、范围和核心流程 | 开始需求或新功能前 |
| `architecture.md` | 分层、依赖方向、外部边界 | 设计跨目录变更前 |
| `implementation-plan.md` | 垂直切片计划与依赖 | 开始实现前 |
| `acceptance.md` | 可验证的验收条件 | 交付前 |
| `adr/` | 架构决策记录 | 架构争议或边界变化时 |

根级约束：

- `AGENTS.md`：项目铁律与工作方式
- `CONSTRAINTS.md`：长期质量、安全和风险分级
- `PROJECT_CONTEXT.md`：当前事实、缺口和非目标
