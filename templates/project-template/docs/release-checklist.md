# 发布清单

发布清单是 SHIP 阶段的唯一入口。它只描述如何验证和交付，不授予登录、发布或付费权限。

## 交付前

- [ ] `npm run verify` 通过。
- [ ] 产物路径、规格、来源和版本均可回溯。
- [ ] 用户确认项已单独列出，未把草稿写成已发布。
- [ ] 没有凭据、Cookie、Token、API 密钥、`.env` 或证书进入交付物。

## 外部动作

- [ ] 登录由用户本人完成。
- [ ] 对外发布由用户本人当次确认并执行。
- [ ] 付费操作按批次取得当次授权。
- [ ] 成功以对方最终回执为准；处理中不算完成。

## 状态更新

- 没有最终成功回执：保持等待确认状态。
- 有最终成功回执：更新为已完成，并写入时间、对象和回执位置。
- 有真实数据：只记录用户提供的数字，缺失写「缺」。

## 回滚

交付失败时保留上一份可用产物，记录失败原因和下一步；不得删除历史证据或覆盖成功版本。
