## 项目识别规则

1. 先读取 `project_state.yaml` 的不可变 `project_id`；
2. 再读取项目 README 和相关资产索引；
3. 不使用线程标题、任务标题或目录显示名判断项目身份；
4. 新增项目必须复制状态契约字段，并在此表登记。

## 状态同步

项目状态变化时，同时更新：

- `project_state.yaml`：机器可读的唯一状态；
- 项目 `README.md`：人类可读的原因、阻塞和下一步；
- 相关任务评论或交付记录：本次变更的证据。
