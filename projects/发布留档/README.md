# 发布留档

这里是自媒体线（念念家族）**发布证据**的存放区：作品页截图、作品链接记录，以及用于复盘汇总的台账工作副本。

## 边界

- 本目录不是项目控制台，不含 `project_state.yaml`，不参与项目身份判定。
- 只放用户本人发布之后产生的真实证据；未发布的内容、预览图和样例图不得放进来冒充已发布。
- 不存放 Cookie、Token、API Key、密码、证书或 `.env`。
- 平台后台数字拿不到时写「缺」，不估算、不编造。

## 命名规则

| 类型 | 命名 | 示例 |
|---|---|---|
| 作品页截图 | 账号_日期_首条.png | 念念带货屋_2026092X_首条.png |
| 台账工作副本 | 数据台账_工作副本.md | 见同目录 |
