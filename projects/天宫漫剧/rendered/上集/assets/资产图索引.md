## 三、本目录的命名规则

上传时**不需要真的把图片拷进本目录**。本目录的作用是给出统一的文件名，方便在 Dola 里对上号。若你希望本地有一份对照，按下面的命名把原图拷进来即可：

```text
rendered/上集/assets/
  characters/
    M01_柳小念_天兵态.png
    M03_孙悟空_弼马温态.png
  scenes/
    M07_南天门.png
    极简内景_高窗冷月光.png
  props/
    M11_天书.png
    M12_幸运大转盘.png
    M13_儿歌三百首_封面态.png
    M13_儿歌三百首_内页态.png
    M14_弼马温马鞭.png
  keyframes/
    seg01_first.png   # seg01 起始帧（人工选或由分镜参考生成）
    seg01_last.png    # seg01 尾帧 = seg02 的 @图片3
    seg02_last.png    # 依此类推，每段尾帧留给下一段
    seg03_last.png
    seg04_last.png
    seg05_last.png
    seg06_last.png    # 上集收尾帧，留给中集 seg01 承接
```

## 四、生产顺序（按依赖倒推）

1. **看图拍板**：M01 / M03 四宫格新版（这两个是上集主角基准，拍板后立即回填本索引）。M07 南天门已验收，可直接用。
3. **上传参考图**：按上面「逐段参考图对应表」逐段上传，先出 seg01。
4. **段间承接**：seg01 的尾帧导出后，作为 seg02 的 `@图片3`；依次类推，一段一段往下滚。
5. **尾帧归档**：每段尾帧落盘到 `keyframes/`，命名固定为 `segNN_last.png`，中集 seg01 用 `seg06_last.png` 承接。
