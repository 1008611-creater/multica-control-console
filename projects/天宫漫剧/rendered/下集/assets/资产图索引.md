## 三、本目录的命名规则

```text
    M04_武明空.png
    M05_天庭天兵群像.png
    M03_孙悟空_弼马温态.png   # 仅闪回帧
  scenes/
    M09_仙朝大唐.png
    M10_神庙天命宗.png
    M08_天界地盘.png
  props/
    M11_天书.png
    M12_幸运大转盘.png
    M14_官印单图.png          # 建庙名分物证
    M16_香火神庙灵光.png
    M17_小世界光门.png
  keyframes/
    mid_seg06_last.png   # 中集末帧（跨集承接，即 seg01 的 @图片3）
    seg01_last.png       # seg01 尾帧 = seg02 的 @图片4
    seg02_last.png
    seg03_last.png
    seg04_last.png
    seg05_last.png
    seg06_last.png       # 下集末帧 = 三集终点，不承接下季
```

## 四、生产顺序（按依赖倒推）

1. **看图拍板**：**M09 仙朝大唐（下集风格锚，最优先）** → M10 神庙天命宗（垫 M09 作风格参考）→ M04 武明空（seg02 依赖）→ M02 凡仙态（全六段主角基准）。拍板后立刻回填本索引。
2. **已验收可直接用**：M08 天界地盘（seg03）、M16 香火灵光（seg04）、M17 小世界光门（seg05/seg06）、M11/M12/M14。
3. **下集六段全部依赖待拍板资产**，暂无可提前开跑的段落；闪回帧素材（seg06 @图片3）随时可用。
4. **上传参考图**：按上面「逐段参考图对应表」逐段上传，段号顺序推进。
5. **段间承接**：每段尾帧导出后，作为下一段的 `@图片4`；下集 seg01 用 `mid_seg06_last.png`（中集末帧）承接。
6. **尾帧归档**：每段尾帧落盘到 `keyframes/`，命名固定为 `segNN_last.png`；下集 `seg06_last.png` 为三集终点，不再向下承接。

> **M09 是下集的第一顺位**：它是整集的**风格锚**（人间暖曙暖橙），M10 建议垫 M09 作 `--sref` 以锁定同风格；M04 武明空的唐制襦裙配色也要与 M09 的朱砂招牌 / 石青檐彩呼应。
