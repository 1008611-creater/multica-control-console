> 版本：v1.0｜日期：2026-08-25｜依据：`chinese-celestial-palace/references/visual-dna.md`

## 风格定义（一句）

## 视觉系统硬约束（全部场景适用）

| 维度 | 约束 |
|------|------|
| 云海 | 至少承担两项职责（托举宫台+遮挡桥墩/分隔远近）；有云顶/云底/体量；不得是棉花球或平面祥云 |
| 建筑 | 柱网开间可读、斗拱承重关系清楚；不使用泛亚洲/日韩/欧式混搭 |
| 尺度 | 每镜头至少一组"人物↔柱门↔整殿"的连续比例证据；单人占画高2-10% |
| 色彩 | 云白/浅石/清透天空为基底；朱砂、石青、石绿、暖金只做局部节奏；禁止全局灰罩与满屏红金 |
| 光线 | 单一主光；云顶暖、云底冷；真实体积散射 |
| 材质 | 朱漆木/暗木梁/青灰瓦/粗粝岩/哑光丝绸；禁塑料红柱与游戏贴图 |
| 镜头 | 天宫镜头慢、稳、庄严；每段单一主运镜；深焦、校正垂直线、稳定水平线 |
| 人物 | 静立/缓行/回望/并肩；不跳跃抢戏；脚下有台基/桥面/地坪并带接触阴影 |

## 反套路红线

- 不用"龙+凤凰+灯笼+祥云+金殿"堆东方符号
- 不把巨月/圆门/孤身白衣设为默认答案
- 不堆飞鹤、花瓣、星尘、法阵等"仙气附件"
- 不复刻参考帧空间排列；保留视觉语法，重做故事、路径、相机与神迹
