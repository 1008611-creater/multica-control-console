## 3. 抽卡软件使用方式（人工 / AI 双入口）

软件目录：`ai-rpa-console/`；开发启动：`npm start`；打包版本：`dist/ai-rpa-console.exe`。

### 3.1 人工批量抽卡

1. 打开本地控制台，点击“启动浏览器”，首次在 MXAI 窗口手动登录并完成滑块。
2. 导入 JSONL/JSON/CSV 任务，先校验，再点击“准备本地批次”。
3. 确认任务数量、MJ 版本、画幅和费用后，点击“批量生成已校验任务”。系统只串行执行，不并发抢浏览器。
4. 结果写入 `.automation/results/`，回执写入 `.automation/receipts/mxai-tasks.jsonl`；“待回读”任务按 serial 回收，不得重新提交。
5. 通过 4 选 1 验收后，才把正式图登记进资产清单。

### 3.2 AI 通过 MCP 抽卡

MCP 服务默认连接已经启动的本地控制台：`RPA_CONSOLE_URL=http://127.0.0.1:4173 node mxai_mcp_server.js`。AI 只调用 `mxai_start`、`mxai_status`、`mxai_generate` 或 `mxai_generate_batch`；实际浏览器、队列、回执都由控制台统一管理。

- `mxai_generate`：提交单张 MJ 任务；
- `mxai_generate_batch`：按顺序提交 1–100 张；
- `mxai_download_latest`：可传 `serial` 精确回收指定任务；
- `mxai_status`：查看当前队列和最近回执。

控制台未启动、未登录、已有任务执行中或等待超时，MCP 返回明确状态；含 serial 的超时任务进入 `receipt_pending`，禁止自动重试。只有显式设置 `RPA_CONSOLE_DIRECT_MCP=1` 才使用旧的直连兼容模式。

### 3.3 渠道硬校验

- M01–M10（人物、建筑、场景）→ **MJ / mxai MCP**；
- M11–M17（道具、特效、光效、奇观主体）→ **OpenLux / image2**；
- 软件的 MXAI 队列不接受 OpenLux 任务，避免渠道误用；OpenLux 任务仍由对应 image2 流程执行并回写同一资产台账。

## 4. 你（老大）在流程里只需要做 4 件事

1. **裁决**：剧本/风格/资产验收/shotlist，看产物说"过"或说哪里不对；
2. **跑图**：拿员工给的"英文粘贴版"去 MXAI 跑，4 选 1；
3. **跑视频**：拿 I2V 提示词+资产图去 Dola 跑；
4. **剪映后期**：配音/字幕/BGM。

其余所有编译、对账、连续性、验收标准，都是线程员工的活。
