## 视觉硬约束（任何人不得漂移）

- 画幅：抖音 9:16 竖屏；成片 1080×1920。
- 人物：修长清俊、长袍轻纱、默认侧脸/背影/逆光轮廓，渺小超然；3D 国漫，非真人摄影语义。
- 场景：中式天宫巨构——朱红立柱、勾心斗角、金瓦、汉白玉、圆月洞门、天瀑、金色云海。
- 质感：电影级 3D 国漫、HDR、冷暖对撞、暖光破口、体积雾、Bloom。
- 禁止：欧美写实战争片风、塑料 CGI、网红妆、正面特写定妆照、满屏红金、全局灰雾、随机文字。
- 风格基线：`assets/12_S7_四类风格锚_v3_敦煌天宫3D仿真人.md` §2.8 权威版 v3.7。
