## 上集《儿歌唤大圣》

| 项 | 内容 |
|---|---|
| 集标题 | 儿歌唤大圣 |
| 原著章节 | 第1—5章 |
| 开场钩子 | 南天门下，一名小兵鬼鬼祟祟掏出天书，对天祈祷"让我中一次吧"——身后是天庭，脚下是凡间，他像一个在赌命。 |
| 主角目标 | 抽中一件能保命的东西，逃离南天门一线炮灰岗位。 |
| 主要阻碍 | 前两次抽奖全是白板；猴哥即将大闹天宫的死亡倒计时。 |
| 两次推进 | ①第三次抽奖爆出金色天阶仙法，狂喜；②翻书一看是《儿歌三百首》，希望又落空。 |
| 反转 | 儿歌竟有引怪功能——对猴哥唱《小星星》"一闪一闪亮晶晶"，真把齐天大圣"唤"到面前。**【影视化补强：原著儿歌歌词为《西游降魔篇》台词，替换为公有领域童谣《小星星》】** |
| 可见结果 | 猴哥被儿歌吸引，柳小念绝地求生，成功刷到好感；猴哥托他代管弼马温。 |
| 关系变化 | 柳小念从"猴哥=催命符"变成"猴哥=机缘"；脱离一线炮灰。 |
| 结尾钩子 | 深夜，天书突然自行发光，一行金色大字浮现——"重铸天庭"。 |
| 高光场面 | 抽奖金光（1-2章）；儿歌唤猴（3-4章）。 |
| 段分配 | ①穿越受困 ②赌命抽奖 ③金光爆出 ④儿歌三百首 ⑤猴哥砸脸 ⑥代管弼马温+天书任务钩子 |

## 中集《天书的任务》

| 项 | 内容 |
|---|---|
| 集标题 | 天书的任务 |
| 原著章节 | 第6—12章 |
| 开场钩子 | 承接上集：天书金字"众仙寂灭、诸神尽绝，重铸天庭，弭化天劫"——他以为只是保命，结果接到了逆天任务。 |
| 主角目标 | 搞懂任务、提升实力，在500年时限前保命并迈出第一步。 |
| 主要阻碍 | 他只是个凡仙境小兵；天庭体制是庞然大物；猴哥也搞不定的事他凭什么。 |
| 两次推进 | ①了解香火功能与凡仙境界体系；②御马监立威，管住十万天马，立住"柳小念"三个字。 |
| 反转 | 他不靠修为硬拼，靠"忽悠+规则漏洞"在天庭立威，证明小兵也能改变规则。 |
| 可见结果 | 御马监上下信服，柳小念踏入凡仙境，被天庭看到。 |
| 关系变化 | 与猴哥的羁绊加深（靠山形成）；对天书从"抽奖工具"到"使命契约"。 |
| 结尾钩子 | 他决定偷下凡尘——"要想重铸天庭，得先看看天庭管不住的人间。" |
| 高光场面 | 天书预言（6章）；御马监立威（8-10章）。 |
| 段分配 | ①天书任务降临 ②解读预言与香火 ③凡仙境界 ④御马监立威 ⑤规则漏洞/忽悠 ⑥下凡钩子 |

## 下集《天命宗》

| 项 | 内容 |
|---|---|
| 集标题 | 天命宗 |
| 原著章节 | 第13—23章 |

| 两次推进 | ①见仙朝大唐/武明空初遇，认知被打开；②回天庭建庙立天命宗，香火汇聚成势力。 |

| 关系变化 | 从孤身小兵到有信徒、有宗门的"准一方之主"；猴哥是身后隐形的盟友。 |
| 结尾钩子 | 神庙功能开启，一座通往未知小世界的光门浮现——重铸天庭的第一站，从这里开始。 |
| 高光场面 | 下凡见大唐（13章）；建庙立宗（17章）；神庙光门（23章）。 |
| 段分配 | ①偷下凡尘 ②仙朝大唐开眼 ③武明空初遇 ④回天庭建庙 ⑤香火汇聚/天命宗立 ⑥神庙光门钩子 |

## 三集关系

- 上集：立世界（西游天庭+金手指）→ 立人物（柳小念/猴哥）→ 第一冲突（炮灰命运）
- 中集：任务降临（重铸天庭）→ 实力立威（凡仙+御马监）→ 决意下凡
- 下集：下凡开眼 → 建宗立基 → 副本门户悬念（重铸天庭第一步落地）

三集合起来是一条完整主线：**保命 → 接命 → 立命**。不吊第二季。
