## 0. 这份基线要解决的问题

老大原话（2026-09-13）：

- 「除了人物不够真实 不够好看 都通过」
- 「人物要那种极致好看的」
- 「但是还是 3D 仿真人的范围 能懂我的意思么」
- 「要四宫格 然后三分之一三分之二的分」

三句话对应三件事，缺一不可：

1. 版式：一条提示词、一次生成、出一张四视图角色设定图；版面按「三分之一 / 三分之二」分区。
2. 质感：走 3D 仿真人，比廉价三维动画皮肤精致，但不是真人实拍照片。
3. 好看：骨相、五官比例、皮肤与发丝按高端角色设定图标准写，不靠画质口号词堆砌。

竖版 9:16 人物设定图，一张图内四个视图同框，纯白无缝背景，无网格线。上排占画面全高约三分之一：左上约六分之一为正面大头特写，右上约六分之一为严格左侧脸大头特写。下排占画面全高约三分之二：左下约三分之一为正面全身，从肩线到鞋，头部自然出画框，聚焦身形比例与服装结构；右下约三分之一为背面全身，从肩线到鞋，头部自然出画框，展示背面服装至下摆。四个视图为同一次生成产出的同一角色：同一年龄、同一发型、同一服装、同一配饰、同一中性表情、同一肤色与材质、同一中性打光、同一色温，无色调漂移。

### 1.3 版面几何（给验收用）

| 位置 | 占比 | 内容 | 取景范围 |
|---|---|---|---|
| 左上 | 约 1/6 | 正面大头特写 | 肩线以上，脸为主体，识别标记必须清晰 |
| 右上 | 约 1/6 | 严格左侧脸大头特写 | 肩线以上，鼻梁与下颌轮廓完整 |
| 左下 | 约 1/3 | 正面全身 | 从肩线到鞋，头部自然出画框 |
| 右下 | 约 1/3 | 背面全身 | 从肩线到鞋，头部自然出画框，下摆到脚 |

上排合计约占全高三分之一，下排合计约占全高三分之二。四个视图之间留白均匀，不加分隔线、不加边框、不加标签文字。

### 1.4 三处必须守住的细节

1. 全身两格是「头部自然出画框」，不是「颈部整齐截断」。旧 M01 / M03 角色设定参考图用的是后者，本基线起改为前者，出框更自然，不会出现无头人偶的观感。
2. 严格左侧脸：写死方向，避免模型随机给右脸或四分之三侧脸，导致与正脸对不上。
3. 纯白无缝背景：无环境、无道具、无地面线、无投影。设定图不是剧照，剧照的场景留给分镜镜头。

## 2. 3D 仿真人质感基线

### 2.1 可直接粘贴的质感句（中文，照抄）

```text
整体质感为中式仙侠 3D 仿真人：高端三维数字人，写实光影与布料高光，理想化的三维面孔而非真人；皮肤有真实毛孔与自然肤色变化，丝织与刺绣有真实材料反应，影棚级角色设定图品质，精致而生动。纯白背景，均匀打光无阴影，无环境元素，无道具，无文字。
审美为顶级中式银幕明星级面孔：骨相比例端正、五官精致协调，立体感与辨识度都做到极致，属于会被一眼记住的好看；精致而自然，绝不甜腻、绝不网红化、绝不用磨皮堆出来的假滑。
```

### 2.2 为什么这样写

「3D 仿真人」是一个窄区间，两边都是坑：

| 跑偏方向 | 表现 | 本基线怎么防 |
|---|---|---|
| 滑向真人实拍摄影 | 毛孔过度、皮肤瑕疵写实、证件照观感、不够好看 | 写「理想化的三维面孔而非真人」；排除项写死 real human photograph |
| 滑向廉价三维动画皮肤 | 塑料感、蜡像感、皮肤过平滑、国漫动画脸 | 写「高端三维数字人 + 真实毛孔与自然肤色变化」；排除项写死 plastic 3D render、smooth 3D skin |

### 2.3 骨相与五官（决定够不够好看）

写角色时按这七条落笔，不要只写「好看」「精致」：

1. 脸型：给出具体形制（例：鹅蛋偏长脸），并交代下颌线与颧骨走向；
2. 比例：五官纵向分布交代清楚（眉、眼、鼻、唇的相对位置），避免模型自由发挥；
3. 眼：写明眼型、眼尾走向、瞳孔色、眼神状态，并要求清晰的眼神光；
4. 鼻：鼻梁挺度、鼻翼宽窄；
5. 唇：唇形与自然唇色，不用浓妆堆砌；
6. 皮肤：真实毛孔与自然肤色变化，禁磨皮、禁过度美颜、禁网红脸；
7. 发：发丝分层与光泽，发际线形态，避免头盔感。

### 2.4 一个固定辨识点（锁脸用）

每个角色必须有一个不破坏美感的固定不对称辨识点，并且要求它在正脸与侧脸特写里都清晰可辨。这是四视图「像同一个人」的验收抓手，也是后续跨镜头一致性的锚。

天宫漫剧现有角色：

| 角色 | 固定辨识点 |
|---|---|
| 柳小念（M01 天兵态 / M02 凡仙态） | 右眼下小泪痣 + 鬓边一缕黛蓝挑染发束 |
| 孙悟空（M03 弼马温态） | 两颊一圈银白短毛亮环 + 雷公嘴微突 |
| 武明空（M04 少女态） | 眼神笃定 + 眉心小痣（后续按出图结果固化） |
| 压迫者天官（M06） | 眉间一道浅竖纹 + 下颌方正 |

### 2.5 光线与材料

- 统一中性影棚打光，四格同一光位、同一色温，无冷暖漂移；
- 均匀打光、不投影，避免某一格被阴影吃掉轮廓；
- 丝绸写「哑光丝绸 / 织锦」而非泛泛的「华服」；金属写「泥金描边」而非「金光闪闪」；
- 甲胄写清层叠结构与内衬，避免糊成一片亮面。

### 2.6 「极致好看」的写法（老大 2026-09-13 定调）

老大对第一批重出图的验收结论是：**人物不够真实、不够好看**；要求是「那种极致好看的」，同时**必须仍在 3D 仿真人范围内**，不能滑向真人实拍照片。

这三条要同时满足，写法上必须分工：

| 目标 | 靠什么达成 | 不能靠什么 |
|---|---|---|
| 真实感 | 真实毛孔、自然肤色变化、真实材料反应、影棚级打光 | 堆画质口号词；磨皮；塑料感 |
| 极致好看 | 骨相七条写细 + 审美强化句 + 高 stylize + 银幕明星级面孔定位 | 只写「好看」「精致」这类空词 |
| 仍在 3D 仿真人区间 | 写「理想化的三维面孔而非真人」；排除项写死 real human photograph | 不写「照片」「实拍」；不禁 --raw 以外的写实词 |

**可直接粘贴的审美句（中文，照抄）**

```text
审美为顶级中式银幕明星级面孔：骨相比例端正、五官精致协调，立体感与辨识度都做到极致，属于会被一眼记住的好看；精致而自然，绝不甜腻、绝不网红化、绝不用磨皮堆出来的假滑。
```

**三个反例，写了就掉档**

1. 只写「面容精致、非常好看」——模型会自由发挥，出来的是平均值脸，没有辨识度；
2. 写「无暇肌肤」「完美皮肤」——直接磨皮，皮肤质感全丢，反而更像塑料人偶；
3. 写「真人级别」「照片级真实」——会越过边界，出成真人实拍，丢掉 3D 仿真人的定位。

## 3. 统一参数档

主参数： `--ar 9:16 --v 8.2 --stylize 750 --quality 2 --chaos 0`

排除项基底（各卡在此之后追加角色专属项）： `--no anime, illustration, cartoon, chibi, plastic 3D render, smooth 3D skin, real human photograph, extra people, text, watermark, logo`

### 3.1 逐项理由

| 参数 | 取值 | 理由 |
|---|---|---|
| `--ar 9:16` | 竖版 | 四格版式需要竖幅容纳「上 1/3 + 下 2/3」；与老大既有角色设定图版式一致 |
| `--v 8.2` | 当前版本 | 与出图通道一致；V8.2 无 --cref，只能靠同一次生成锁脸 |
| `--stylize 750` | 偏高 | 设定图要极致好看，需要模型在骨相与五官上做理想化提升 |
| `--quality 2` | 高 | 皮肤、发丝、刺绣细节需要更多算力 |
| `--chaos 0` | 零 | 四格同人的前提：chaos 越高四格越容易各画各的，直接破坏锁脸 |

### 3.2 为什么不用 --raw

风格锚 §3 明文「不加 --raw」。--raw 会削弱风格化修饰、把皮肤推向写实摄影，与「3D 仿真人」以及「极致好看」都相反。

### 3.3 为什么排除项只放具体名词

风格锚 §4 纪律：--no 只保留防模型脑补污染的具体名词，约 7±2 个，不用负面词去调风格方向。负面词一多，模型容易反向理解。防太真人靠正向质感句 + 禁 --raw + 合适 stylize，不靠堆负面词。

## 4. 视角词与占比词的分工纪律

历史上出过一次混淆：把「人物在画面里占三分之一」和「三分之二侧影」写在一起，结果模型分不清是在讲构图占比还是在讲机位角度。本基线起彻底分开：

| 用途 | 只用这些词 | 禁止 |
|---|---|---|
| 讲版面分区 | 六分之一、三分之一、三分之二（占比） | 不用「三分之二侧影」这类把占比当视角的写法 |
| 讲机位角度 | 正面、严格左侧脸、背面、平视 | 不在设定图里写「微仰」「肩后」等剧情镜头语言 |

设定图一律用中性平视。剧情镜头里的仰拍、肩后、过肩等语言属于分镜，不进设定图，否则四格视角不一致，锁脸失效。

## 6. 平台事实（为什么只能「一次生成出四格」）

- 当前出图通道不支持垫图 / 参考图（无 --cref、无 --oref），所以「先出一张母图、再垫母图出角色卡」的两步法走不通；
- 四视图身份一致只能靠「同一条提示词、同一次生成」实现；
- 比例参数在提交时单独指定，提示词里的 --ar 只作对照记录，实际以提交时选择的 9:16 档位为准；
- 因此每次提交前建议先用免费的比例自检确认档位，再付费出图，避免比例错了还扣积分。

## 7. 与技能库的关系（重要说明）

2026-09-13 对技能库做了全量检索（C 盘用户目录下的 .codex 技能目录及插件缓存，约 1600 余份文档），结论：

- 技能库里没有「四宫格 + 三分之一三分之二 + 纯白底」这套版式：「四宫格」「四视图」「六分之一」均无命中；
- 技能库里最接近的是 mx-shortdrama-04-character-assets 的「16:9 单人多宫格角色设定卡」，但那是横版 16:9，且该技能明文禁止在一条提示词里同时要求定妆剧照与多宫格设定卡；
- 「三分之二」在技能库中出现的三处（ai-video-asset-prompts、mx-shortdrama-00-router、mx-shortdrama-04-character-assets）讲的都是人物占画面的比例，不是本基线的版面分区；
- 另有一处同名不同义：mj-automation 文档里的「四宫格」指的是 Midjourney 原生一次出 4 张候选图、下载为一个文件，那是候选图机制，与角色设定图的四视图版式是两回事，不要混用。

所以本文件是这套版式在天宫漫剧里的唯一权威来源。老大既有的版式硬规则在念念旅行团提示词包 §0.5，本文件把它翻译成天宫漫剧可执行的角色设定图基线。
