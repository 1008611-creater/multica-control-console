## 剧本事实

- **场景**：南天门（天庭正门）
- **出场**：上集场次1-5（全剧核心场景）、中集场次6（偷下凡尘）
- **关键特征**：巨门+云海+渺小人物尺度锚
- **光色**：上集场次一为晨光（暖曙/清冷晨雾+中央金光）；中集场次六为决绝跃下云海
- **建筑**：朱红巨柱、勾心斗拱、金色屋瓦、汉白玉承台、飞檐翘角
- **基调**：庄严肃穆，敬畏感（非宏大感），渺小人物面对巨构的压迫

## 视觉方向锁定

| 项目 | 锁定 |
|---|---|
| 视角 | 远景全景，或门洞内窥视（人物从门内看出去，或从门外看门内） |
| 人物比例 | 1-3% 极渺小，只作尺度锚 |
| 构图 | 门洞框景（人物在门洞中央），或门柱侧全景（人物在柱侧） |
| 光线 | 晨光/暖光从左侧或上方打来，暖光破口在柱头与金瓦上 |
| 色彩 | 暖白+雪白+暗青基底，朱红+暗金仅作局部叙事色 |
| 云海 | 体积感，金色反光，托举巨构 |
| 画质 | 中国仙侠 3D 动画环境概念设计，深焦，电影级 HDR |
