# Multica 本地控制台

这是适用于 Windows 的 Multica 本地控制台。它连接本机抽卡桥，帮助你查看服务与浏览器状态、手动提交任务，并查看作业记录和回执。

## 可以做什么

- 在本机地址 `http://127.0.0.1:8765` 启动抽卡桥。
- 打开中文操作台，查看服务、浏览器、自动看护、作业和回执状态。
- 由你本人决定是否打开浏览器并完成登录。
- 自动看护默认暂停；软件启动时不会恢复旧的生成任务。

软件不会打包 Cookie、Token、密码、API Key 或已登录的浏览器档案，也不会自动发布内容或自动提交付费任务。

## 安装与首次使用

1. 双击当前交付目录中的 `Multica-Control-Console-Setup-*.exe`，选择安装文件夹。升级时请选择原来的安装文件夹。
2. 安装脚本按设计会保留原安装目录里的浏览器档案、任务、回执、图片、运行记录和 `config/local.ps1`。这项升级保留行为尚未通过隔离环境实测；升级前请先复制备份这些本地资料。
3. 安装器会带上 Python 和 Node.js 运行时，并准备抽卡桥依赖；Microsoft Edge 仍需本机安装。首次安装时通常不需要另外安装 Python 或 Node.js。
4. 安装完成后，可使用桌面快捷方式（若安装器创建成功），或打开安装目录双击 `Start-Multica.cmd`。
5. 在工作台点击“打开登录浏览器”，然后由你本人登录。软件安装和启动时不会自动登录或提交任务。
6. 使用完毕后双击 `Stop-Multica.cmd` 停止控制台。

浏览器档案位于 `runtime/browser-profile`，任务与回执位于 `mj-automation` 下。安装脚本设有跳过这些目录的规则，但实际升级保留仍待隔离环境验证。请勿把这些目录发给他人。

## 安全设置

- 服务只监听本机地址 `127.0.0.1`，局域网中的其他设备无法直接访问。
- 自动看护启动时处于暂停状态。
- 每次付费出图都需要在工作台明确确认；页面不会自动重提任务。
- 软件不会读取或导出 Cookie、Token、密码或 API Key。
- 图片、回执、运行记录和浏览器档案保留在本机。

## 本机设置

只有在需要更改端口、代理或服务地址时，才将 `config/local.ps1.example` 复制为 `config/local.ps1`。不要在此文件中保存账号密码或访问密钥。

## 常见问题

- 如果提示缺少 Python 或 Node.js，请安装对应软件后，再运行 `Setup-Multica.cmd`。
- 如果工作台打不开，双击 `Stop-Multica.cmd`，然后再双击 `Start-Multica.cmd`。
- 如果页面显示未登录，请在已经打开的 Edge 窗口中完成登录，并等待平台页面加载稳定。
- 如果启动失败，可查看 `mj-automation/run/logs/portable-server-error.log`。日志仅供本机排查，不要发送包含个人信息的内容。


## 升级验证状态

- 已从安装脚本确认升级时会跳过本地任务、回执、输出、归档、浏览器档案和 `config/local.ps1`，已存在的 Python 运行环境也不会被新包直接替换。
- 这只是源码检查；隔离安装、升级后的数据哈希对照及另一台 Windows 电脑首次启动尚未验证。当前版本不要把这段源码检查理解为升级实测通过。
