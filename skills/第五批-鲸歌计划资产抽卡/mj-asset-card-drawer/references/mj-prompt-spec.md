# MJ 资产抽卡编译规范

## Prompt 字段顺序

```text
资产 ID 与职责；主体身份锚点；环境身份；动作或状态；材质与结构；光线与空气；构图与景别；D083 色彩寄存器；真实摄影与原创转译声明；画面文字限制；参数建议；局部 --no
```

## 固定视觉基准

使用 D083 诺兰色彩寄存器，但不要复刻任何具体电影：

- 诺兰钢蓝 `#40596D`：大面积天空、海面、冰层、深海环境。
- 沙滩灰褐 `#8D806D`：旧船体、建筑、木桌、服装的第二层。
- 城市水泥 `#747B7C`：人物、仪器、金属和核心道具。
- 警示橙 `#B26834`：只作为危险、时间压力或转折的局部信号。
- 正装黑 `#1B1E23`：深海黑位、设备、阴影和反射。
- 云层白 `#C3C5BF`：冰壳、探测器冷光、声波和转折强调。

基调：低饱和冷中性、自然世界内光源、大尺度实景摄影感、稳定构图、精确尺度、克制表演。避免自动添加青橙大片滤镜。

## 四宫格硬性验收

- 人物必须使用竖版 `--ar 9:16`，作为视频模型参考输入；不能回退到 16:9、4:5 或 3:2。
- 人物版式必须是两列不等高布局：每列上格高度约 `1/3`、下格高度约 `2/3`，上排高度约为下排一半；左上正面大头、右上 `90°/75°` 侧脸、左下正面全身、右下背身全身；如按整图面积换算，上排单格约 `1/6`、下排单格约 `1/3`；提示词中必须出现对应的版式声明。
- 人物只有左上格一次正面大头照；左下为正面全身，右上为侧脸，右下为背身全身；四格不串格。
- 关键道具继续使用独立的竖版 `--ar 9:16` 四宫格规则，除非用户另行指定。
- 道具四格必须属于同一件物体，四个角度互补，不得将四种候选道具拼在一张图中。
- MJ 可能破坏分格或重复脸，必须人工检查；失败时先重跑版式与格间留白，不先修改人物身份或道具材质。

## 参数策略

- 人物母板：`--ar 9:16`，视频模型参考输入四宫格硬版式，中等 `--stylize`，先锁脸、侧脸和服装，再做场景变化。
- 环境母板：`--ar 16:9`，中低 `--stylize`，先锁空间关系和光源，再做天气变化。
- 道具/生物母板：关键道具使用 `--ar 9:16` 四宫格；只需要单一生物远景或场景关系时才使用 `--ar 16:9`。
- 未知参数或版本差异时删去参数，只保留 prompt 正文并记录 MJ 版本、日期和种子。
- 第一轮一次只改一个变量；不要同时换脸、换服装、换光线和换构图。

## P0 失败回退

1. 角色脸漂移：缩短背景描述，重复身份锚点，改为受控半身卡。
2. 场景泛化：补充功能物件、尺度参照和动机光源，不增加更多风格形容词。
3. 生物变成普通鲸或怪兽：明确“只露局部/远距轮廓/不完整揭示”，补充非标准轮廓与受损细节。
4. 屏幕产生伪字：改为无文字波形、网格和光带，文字全部后期叠加。
5. 画面过度赛博朋克：删除霓虹、紫色灯带和发光装饰，回到真实设备光与自然天气光。
