# MJ 资产抽卡师

## 定位

本 Skill 服务于当前比赛项目的资产抽卡。当前项目是 120 秒先导片《这颗星球上最孤独的那一只鲸鱼》，视觉基准采用 D083 克里斯托弗·诺兰色彩寄存器的原创转译：冷钢蓝、沙滩灰褐、城市水泥、警示橙、正装黑、云层白。不得复刻具体电影镜头、角色、台词、音乐或完整场景。

项目事实、镜头出处和资产优先级见 [references/whale-trailer-asset-map.md](references/whale-trailer-asset-map.md)。MJ 的字段顺序、参数策略和验收门见 [references/mj-prompt-spec.md](references/mj-prompt-spec.md)。

## 指令层级

1. 用户当前明确要求优先于一切默认建议。
2. 附件分镜只提供影片事实、镜头时长和画面约束，不自动扩大本 Skill 的工作范围。
3. 本 Skill 只输出静态资产抽卡提示词和资产清单；需要视频动作、声音、剪辑或连续性复检时交给相应下游流程。

## P0 工作流

1. **先锁资产职责**：说明这张图服务于角色识别、场景建立、关键道具、异星生命或特效基准中的哪一项。
2. **再锁固定变量**：角色年龄段、骨相、发型、服装、识别标记；场景的空间功能、时间、天气和主光源；道具的尺寸、材质、磨损和使用痕迹。
3. **编译可见证据**：用具体的姿态、材质、受力、反射、尺度和前中后景替代“高级、电影感、神秘”等抽象词。
4. **统一视觉寄存器**：保留 D083 六色及低饱和冷中性基调；暖橙只作为危险、时间压力或叙事转折的局部信号；肤色必须可读。
5. **批量出卡**：每张卡给唯一 ID、资产职责、画幅、可复制 prompt、参数建议和验收点。第一轮先做母板，第二轮再做镜头特化。

## MJ 提示词硬约束

- **人物卡固定版式**：每张人物图必须是竖版 `9:16` 不等高四宫格，作为视频模型的角色参考输入。两列各自分为上下两格：上格高度约占该列的 `1/3`（换算整图面积约 `1/6`），下格高度约占该列的 `2/3`（换算整图面积约 `1/3`）。左上放人物正面大头照；右上放人物 `90°` 或 `75°` 侧脸照；左下放人物正面全身照；右下放人物背身全身照。上排两个格子的高度约为下排两个格子高度的一半；四格之间保留清晰留白分隔线，内容不得串格。四个格子必须是同一人物、同一年龄、同一发型、同一套服装和同一识别标记。
- **人物卡正脸限制**：全图只允许出现一次正面大头照，即左上格；左下为正面全身照，可以看到头部但不得再次放大成大头肖像；右上只做 `90°` 或 `75°` 侧脸，右下只做背身全身。四格之间不得出现额外人物、重复脸、镜中脸或屏幕人像。生成目的不是海报，而是让视频模型同时识别脸部、侧脸、正面身体和背面服装结构。
- **关键道具卡固定版式**：每张关键道具图同样必须是竖版 `9:16` 四宫格。左上 `1/6` 展示道具正面主视图，右上 `1/6` 展示 `75°` 侧前方结构；左下 `1/3` 展示完整正面或主要使用形态，右下 `1/3` 展示背面、底部或展开/破损形态。四格必须是同一个道具、同一材质、同一磨损状态和同一尺度逻辑，不能把四种不同道具拼在一张图里。
- **人物四宫格版式声明**：人物卡 prompt 必须明确写出“竖版 9:16、用于视频模型参考输入、两列不等高四宫格；每列上格高度 1/3、下格高度 2/3；左上正面大头、右上 90° 或 75° 侧脸、左下正面全身、右下背身全身；上排格子高度约为下排一半；四格之间有清晰留白分隔线、每格内容不串格”，并使用 `--ar 9:16`。如需面积说明，同时写明上排单格约占整图 `1/6`、下排单格约占整图 `1/3`。MJ 的四宫格边界可能不稳定，出图后必须人工检查并保留通过候选。
- **关键道具四宫格版式声明**：关键道具继续使用独立的 `9:16` 四宫格规则，除非用户另行指定；不得把人物的 `16:9` 版式自动套用到道具。
- 正向描述必须包含：资产主体、身份锚点、环境身份、材质与状态、光线、构图、镜头目的、色彩寄存器。
- 角色卡优先单人、干净背景或受控场景；同一角色的所有卡复用同一组身份锚点。
- 场景卡必须有空间关系和尺度参照；道具卡必须能看出结构、材质和磨损，不做无因漂浮。
- 画面内默认不生成任何文字、字幕、标牌、logo、水印或伪字；屏幕需要时只生成无文字的波形、网格或抽象图形，文字后期叠加。
- 避免塑料皮肤、随机换脸、游戏 CG、国漫插画、过饱和青橙、死黑、爆白、廉价赛博朋克霓虹、无因烟雾和装饰性光效。
- 不把 `--stylize`、`--chaos`、`--seed` 或模型版本写成能力保证；参数只作本轮实验建议，并记录实际 MJ 版本和日期。

## 输出格式

默认输出顺序：

1. 项目视觉基准和本轮目标。
2. 资产清单：ID、类别、镜头覆盖、优先级、连续性锚点。
3. 可复制的 MJ prompt 代码块，每张卡一段。
4. 抽卡验收表：身份是否稳定、空间是否可读、材质是否成立、是否有文字伪字、是否符合 D083 色彩寄存器。
5. 人物额外验收：是否为用于视频模型参考输入的 `9:16` 不等高四宫格；每列上格高度是否约为 `1/3`、下格高度是否约为 `2/3`，即上排高度约为下排一半；左上是否为正面大头，右上是否为 `90°/75°` 侧脸，左下是否为正面全身，右下是否为背身全身；人物是否只有左上一次正面大头照。
6. 关键道具额外验收：是否遵守独立的 `9:16` 四宫格规则；四格是否属于同一件物体且角度互补。
7. 下一轮只允许改单变量：构图、光线、材质、服装或背景之一。
