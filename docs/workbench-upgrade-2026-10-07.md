## 已实现的产品路径

1. **准备创意**：简洁中文输入、高级参数按需展开；批次草稿、未加入的输入和模板保存在当前浏览器。支持 TXT、CSV、JSON、JSONL，单次最多 2 MB、500 项。非法 CSV Raw 值直接报错，不替换原草稿。
2. **组织实验**：行内编辑、批量参数、复制与移除；选中创意可展开 Stylize × Chaos 组合，提交前看到任务数量；模板和已保存批次输入可复用。
3. **检查并保存**：后端检查参数、重复任务和输出位置。保存产生真实 validated 批次，不派发；开始与继续需独立费用确认。Ctrl+Enter 只打开检查。
4. **运行与批次**：本地排队、浏览器锁等待、准备、提交确认中、平台生成、下载、完成和待核查分别显示。费用、已提交和回执缺失保留未知，不显示假进度或猜测平台队列。
5. **图片工作区**：从真实作业、尝试和回执索引本地成品；原图预览、最多四张比较、标签、收藏、筛选、归档、定位和导出清单。原文件不被裁剪或修改。
6. **复用经验**：有记录的提示词与参数可进入下一轮草稿；不携带旧授权或执行状态。八张用于验收的历史图片缺原提示词，界面显示「缺」并禁用完整复用。

统一使用暖白、灰绿、深绿、清晰层级和一致按钮；窗口从 1440 到 390 像素检查整体溢出。表格在容器中横向滚动。技术诊断和完整回执按需展开。支持 Alt+1–4 导航、预览左右切换、Tab 弹窗循环和 Escape 关闭。

## 可靠性与状态决策

- 用提示词、画幅、版本、完整参数和档案路径计算请求身份；子进程启动前原子保存提交意图。超时或回执不明返回作业号并禁止重复派发，force 也不绕过未决意图。
- 使用唯一作业号及输出名后缀，减少同名任务串图和覆盖；下载必须关联本次 serial，不拿历史「最新图片」充当本次成品。
- 共享浏览器档案实际只派发一路；独立档案本地调度最多三路，各自需用户登录。三路真实平台执行尚未验收。
- 已提交任务取消后仍收回执；恢复关联原作业，不产生新提交。重启不会自动继续付费补位。
- 接口费用确认只接受 JSON 布尔 true，字符串或数字不能算授权。浏览器确认勾选不会持久化到下一次操作。
- 图库不接客户端路径，拒绝符号链接/目录联接、HTML 伪装图片及明显格式异常；PNG/JPEG/WebP 结构检查不是完整像素解码。验收的八张原图另外由 Edge decode 检查。
- 标注使用锁和原子写入，损坏文件停止覆盖；浏览器损坏草稿先保留备份，备份失败禁止静默覆盖。
- `/control/` 拒绝外域与 null Origin；保留 `/v1` 的画布跨域契约。这是本地同源防护，不宣称完整 CSRF/DNS 重绑定防御或任意文件变更时的完全竞态防护。
- 参数状态为 `transport_only`：确认进入实际发送文本，不宣称平台采用；登录、费用与平台回执缺信息时显示「缺」或未知。

新增决定见 [ADR 0011](./adr/0011-creative-workbench.md)，补充而不抹去历史 ADR 0010。
