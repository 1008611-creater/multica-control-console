# 产品规格：Multica 本地抽卡生产工作台

更新时间：2026-09-27
状态：产品方向已由用户明确；已实现能力仍须按验收证据逐项确认。

## 1. 产品定位与职责

Multica 本地抽卡生产工作台是一款面向 Windows 的全中文本地软件，用来准备抽卡任务、管理有上限的并发队列、读取真实执行回执、定位成品并判断失败后的下一步。完整的目标体验和页面信息结构见 [`multica-workbench-product-vision.md`](multica-workbench-product-vision.md)。

本仓库提供工作台源码、安装/分发入口、产品规则和可复核的状态/回执索引；已安装的软件在用户机器上运行并保管本机数据；Multica 桌面端和图像平台属于外部执行现场。任何一层都不能用计划、按钮点击或推断冒充平台真实结果。

## 2. 核心用户问题

用户需要在一个地方看懂任务当前状态、哪些正在执行、哪些还在排队、平台实际返回了什么、成品保存在哪里、失败是否可安全重提。错误状态和模糊扣费信息必须显眼，未知值显示“缺”。

## 3. 首版必需能力

- 全中文的总览、任务队列、任务详情、回执与成品位置。
- 队列按用户顺序工作，最多同时运行三项；界面展示已占用槽位和等待原因。
- 任务详情保留提示词、参数、每次提交尝试、平台标识、真实回执、费用确定性和成品文件清单。
- 失败时说明已核实的原因、扣费状态和重提条件；不确定时禁止自动重提。每次重提都新增尝试记录。
- 登录、付费提交、最终选图和发布各有清楚的人工确认边界。免费检查明确说明不会登录、提交、出图或扣费。
- 安装与升级保留本地任务、回执、输出、配置和浏览器档案；程序更新与用户数据保存分开。
- 面向普通用户提供清楚的成品位置、失败说明、启动/停止方法和可复制诊断摘要。

## 4. 禁止行为与范围边界

软件不自动登录、自动发布、自动支付、自动重试或静默扩大提交范围；不读取或导出 Cookie、Token、密码、API Key 或浏览器登录态；不通过本地像素编辑制造或冒充生产图。登录、付费生成和对外发送均需当次明确授权。

## 5. 验收原则

离线样例只能证明程序可处理样例，不能证明真实桥或平台当前返回。正式验收须分别核对中文界面、三并发调度、真实回执与成品映射、付费确认闸门、失败和重提判定、Windows 安装启动停止及升级数据保留。未完成真实运行回读的条目标记为“未验证”。具体检查项由 [`acceptance.md`](acceptance.md) 维护。

## 6. 各系统职责

- Multica 负责外部任务编排和运行；本地工作台不替代 Multica 客户端。
- 图像平台负责生成与平台账务；本地工作台记录可回读的结果，不猜测未知信息。
- 用户负责本人登录、付费确认、最终选图、发布和对外发送。
- 历史自媒体、漫剧及技能资产可作为任务输入或索引材料，不再构成与本工作台并列的产品定位。
