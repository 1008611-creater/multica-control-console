# 发布清单

发布清单是 `SHIP` 阶段的唯一入口。它只描述如何验证和交付，不授予平台登录、发布或付费生成权限。

## 交付前

- [ ] `npm run verify` 通过。
- [ ] 相关项目 `project_state.yaml` 的 `project_id` 已确认。
- [ ] 产物路径、规格、来源和版本均可回溯。
- [ ] 用户确认项已单独列出，未把草稿写成已发布。
- [ ] 没有凭据、Cookie、Token、API Key、`.env` 或证书进入交付物。

## 外部动作

- [ ] 登录由用户本人完成。
- [ ] 发布由用户本人当次确认并执行。
- [ ] 付费生成按批次取得当次授权。
- [ ] 发布成功以平台最终回执为准；上传中、处理中不算完成。

## 状态更新

- 无平台成功回执：保持 `awaiting_review` 或 `accepted`。
- 有平台成功回执：更新为 `shipped`，写入时间、作品和回执位置。
- 有真实后台数据：进入 `measured`，只记录用户提供的数字。

## 回滚

发布失败时保留上一份可用产物，记录失败原因和下一步；不得删除历史证据或覆盖成功版本。
