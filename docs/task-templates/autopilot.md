# 模板：Autopilot 派工切片

## 元数据

- 风险等级：L2
- 责任角色：自媒体主控

## 目标

把周期性的派工动作固化成一条可复核的任务输入：到点产生任务，但不执行发布，也不触发任何平台动作。

## 输入

- 触发时间和时区：`Asia/Shanghai`；
- 目标小队和队长；
- 对应内容/数据任务模板；
- 当前项目 ID 和验收条件。

## 输出

- 任务标题模板；
- 任务正文（包含输入、输出、红线、验收）；
- 失败时的重试或人工介入条件。

## 硬约束

- Autopilot 只能派任务，不能登录、发布或触发未经授权的付费生成；
- 输出模式使用“创建任务”；
- 任务必须指向小队和队长，不得悬空；
- 数据任务只能请求用户提供真实数据。

## 验收

- [ ] 时区明确；
- [ ] 目标小队、队长和项目 ID 明确；
- [ ] 任务正文引用对应模板；
- [ ] 明确写出“不发布、不登录、不代替用户确认”。

## 失败处理

目标小队、队长或时区缺失时，不创建任务，先输出缺失项和解除条件；到点无人接收时保留原任务，不重复派发。
