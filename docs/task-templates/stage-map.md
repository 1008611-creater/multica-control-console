# 阶段操作卡与任务模板映射

旧阶段操作卡继续保留为具体操作说明；创建新 Multica 任务时，先套模板，再引用操作卡中的细节。

| 现有操作卡 | 使用模板 | 责任角色 | 进入条件 |
|---|---|---|---|
| `04_阶段0_唤醒Multica.md` | `autopilot.md` | 自媒体主控 | 运行时可用、代理在线 |
| `05_阶段1_技能与智能体.md` | `content-production.md` | 自媒体主控/内容生产 | 技能可见、智能体可用 |
| `06_阶段2_Autopilot.md` | `autopilot.md` | 自媒体主控 | 小队与队长已配置 |
| `07_阶段4_三成片发布清单.md` | `review-and-release.md` | 发布准备/用户 | 内容已验收 |
| `03_上手清单.md` 数据闭环部分 | `data-review.md` | 数据复盘 | 用户提供真实数据 |

## 使用顺序

```text
项目状态 → 对应任务模板 → 阶段操作卡细节 → 产物 → 验收 → 回写状态
```

阶段操作卡不能覆盖 `AGENTS.md`、`CONSTRAINTS.md` 或项目状态契约中的红线。
