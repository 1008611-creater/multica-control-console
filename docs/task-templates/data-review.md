# 模板：数据记账与复盘切片

## 元数据

- 风险等级：L1
- 责任角色：数据复盘
- 项目身份：填写不可变 `project_id`

## 目标

只使用用户提供的真实后台数据，完成当天记账或周复盘，不推断缺失结果。

## 输入

- 用户提供的后台数字、截图或链接；
- 当前项目和账号的真实发布记录；
- 数据台账现有行。

## 输出

1. 追加后的台账行；
2. 缺失字段清单（统一写「缺」）；
3. 有证据的结构判断；
4. 下一步建议和待用户拍板项。

## 硬约束

- 没有真实数据就写“数据不足，无法判定”；
- 不登录平台、不抓取后台、不估算播放、销量或完播率；
- 每条结论附作品名和时间依据。

## 验收

- [ ] 未报字段均为「缺」；
- [ ] 未发布账号标记为「未发布」，不填 0；
- [ ] 结论均能回到具体数据行；
- [ ] 没有把建议写成保证或事实。
