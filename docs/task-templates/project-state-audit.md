# 模板：项目状态一致性审计

## 元数据

- 风险等级：L1
- 责任角色：自媒体主控
- 外部动作：无登录、无发布、无付费生成

## 目标

确认一个项目的身份、状态、交付物、阻塞项和授权边界与控制台索引一致。

## 输入

- `PROJECT_CONTEXT.md`
- `CONSTRAINTS.md`
- 项目 `project_state.yaml`
- 项目 `README.md`
- `projects/README.md`

## 输出

- 一份审计回执，包含逐项 PASS/FAIL 证据；
- 不一致项、影响范围和修复建议；
- 明确下一步及其授权门。

## 验收

- [ ] `project_id` 在状态文件、项目 README 和项目索引中一致；
- [ ] 状态属于契约枚举；
- [ ] 交付物路径可定位，缺失项明确写出；
- [ ] `blockers` 与项目内部待审核项没有被混为一谈；
- [ ] 授权边界完整，未触发外部动作；
- [ ] 回执保存到项目 `receipts/` 目录。
