# 模板：复核与发布准备切片

## 元数据

- 风险等级：L2
- 责任角色：发布准备
- 把关角色：用户本人
- 项目身份：填写不可变 `project_id`

## 目标

把已完成的内容整理成用户可以逐项确认的发布执行卡，并完成事实、合规和素材完整性检查。

## 输入

- 已验收内容产物及文件路径；
- 对应项目状态和生产规格；
- 用户提供的真实数据或截图（如有）。

## 输出

1. 视频/图片文件路径与存在性检查；
2. 标题、描述、互@、话题、封面、建议时段；
3. AI 生成内容声明与合规备忘；
4. 发布前用户确认项；
5. 发布后回执与数据回填说明。

## 硬约束

- 只做准备，不登录、不上传、不发布、不代替用户确认。
- 不读取或保存 Cookie、Token、API Key、密码或证书。
- 没有真实后台数据时标记「缺」，不推断效果。
- 只有用户本人在平台完成发布并提供最终成功回执后，项目状态才能进入 `shipped`。

## 验收

- [ ] 五件套齐全且与账号/时段一致；
- [ ] 所有风险和待确认项明确列出；
- [ ] 发布动作仍由用户执行；
- [ ] 回执字段和数据台账入口已准备。

## 失败处理

素材缺失、规格不符或合规风险未解决时，状态保持 `awaiting_review`，不得标记为已发布。
