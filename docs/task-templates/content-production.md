# 模板：内容生产切片

## 元数据

- 风险等级：L1；跨项目素材或付费生成时升级为 L2/L3
- 责任角色：内容生产
- 把关角色：自媒体主控
- 项目身份：填写不可变 `project_id`，禁止只写任务标题

## 目标

基于已确认的选题和项目状态，产出一份可审核的内容草稿，不直接发布。

## 输入

- `PROJECT_CONTEXT.md`
- `CONSTRAINTS.md`
- 对应项目的 `project_state.yaml`
- 已确认选题、事实来源和可用素材路径

## 输出

1. 分镜级脚本：时长、画面、台词/字幕、声音；
2. 素材清单：已有、缺失、来源和授权状态；
3. 发布包草稿：标题、描述、话题、封面建议、建议时段；
4. 风险清单：事实缺口、版权/合规风险、需要用户拍板的事项。

## 硬约束

- 规格默认 9:16、1080×1920；项目自有规格优先。
- 不编造播放、销量、客户反馈或平台推荐结果。
- 付费生成前必须停下并请求当次授权；授权不写入脚本或日志中的秘密。
- 不登录、不发布、不自动点击平台 UI。

## 验收

- [ ] 输出引用了真实项目 ID 和来源路径；
- [ ] 每个产出都有可追溯文件路径或明确标记为「缺」；
- [ ] 发布包五件套完整；
- [ ] 未执行发布或付费调用；
- [ ] 用户拍板项单独列出。

## 失败处理

输入不足时输出“阻塞原因 + 缺失项 + 解除条件”，不要用默认事实补齐。
