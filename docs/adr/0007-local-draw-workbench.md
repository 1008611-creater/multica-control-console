# ADR-0007：本地抽卡桥工作台

- 日期：2026-09-27
- 状态：接受并进入实现

## 决策

在 `http://127.0.0.1:8765/control` 提供本地可视化工作台。仓库负责保存可审查的页面、桥接服务和安装/构建源码；安装后的软件负责显示本机状态并保管本机数据；Multica 桌面端、浏览器与图像平台属于外部执行现场。桥接服务是唯一调用 `POST /v1/jobs` 的组件。

## 职责边界

- 页面加载、健康检查、作业与回执查询，以及 `POST /v1/maintenance` 输入检查不会创建付费图片。
- 只有用户查看对象与范围、勾选付费确认、点击提交并通过浏览器确认后，才发送 `POST /v1/jobs`。
- 用户在可见浏览器中自行登录；工作台不读取或保存 Cookie、Token、密码或密钥。
- 提交后页面查询返回的 `jobId`；遇到失败、排队或未完成状态时不自动重提。
- `/` 重定向至 `/control`，使桥地址直接打开工作台。

## 验收依据

- `/health` 返回构建标记 `2026-09-27-workbench-01`。
- `/control` 含提示词、比例、版本、标签、请求预览、付费确认、作业跟踪和回执查看。
- Python 与 Node 语法检查以及 `npm run verify` 通过。
- 本决策不调用 `/v1/jobs`，不生成图像，不访问付费生成接口。

## 分发与数据边界

- 页面和安装器源码留在仓库审查；`/runtime/` 作为本机依赖目录，其中可能有用户浏览器档案，不得把真实档案复制进安装包。
- `/dist/` 存放按版本生成的分发件。重建版本前会删除同名目录与 ZIP；须先备份现有产物并验证能恢复。
- 安装器采用合并复制，保留 `runtime/python`、`runtime/browser-profile`、`mj-automation/run`、`mj-automation/output`、`mj-automation/archive`、`mj-automation/receipts` 和 `config/local.ps1`；已有 Python 运行时不会被新包替换。以上只完成源码检查，隔离升级与恢复仍待实测。
- `.playwright-cli/` 的验收证据、`mj-automation/receipts/` 的真实回执、生成媒体和依赖目录属于不同类别，不能批量清理。

## 验证边界

包清单和 ZIP 路径名只能核实声明字段与包含路径，不能证明干净机器安装、升级数据保留或真实平台链路通过；这些仍是独立的验收项。
