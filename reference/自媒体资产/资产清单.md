## 七、没有收录的内容（以及为什么）

| 没收录 | 原因 |
|---|---|
| 视频、图片等大文件 | 体积大，且原料库就在本机，复制是浪费；只做索引 |
| 头像生成的中间产物 | 过程文件，无复用价值 |
| 缓存、临时目录、依赖包 | 可再生成 |
| 密钥、令牌、Cookie、密码、证书 | **安全红线，一律不落地** |
| 第三方开源仓库 | 会持续更新，复制会立刻过期；见 `开源项目索引.md` |
