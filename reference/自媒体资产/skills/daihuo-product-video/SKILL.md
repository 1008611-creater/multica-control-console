# 念念带货屋 · 商品视频生产线

账号角色：近端变现。核心指标：商品资料提交、商家咨询、试单、交付成本。

## 生产线

1. **素材核验**：只使用真实商品图/实拍。登记素材来源与可表述边界到 `drafts/<商品>-<日期>/source-check.md`。不虚构销量、功效、材质、客户评价。
2. **卖点动作化**：每个卖点翻成一个可见动作镜头（如"防水"→泼水测试镜头）。写入 `script.md`，一镜一卖点。
3. **成片方式**（按需选一）：
   - 图转视频：商品图 → Seedance 2.5 I2V 提示词（锁商品主体不变形）；
   - 原图剪辑：按原图顺序做竖版卡点/运镜，不重绘不加贴纸；
   - 前后对比：图转视频前后并置，强调"真实商品"。
4. **生成候选**：≥2 条给老大挑，检查商品不变形、卖点动作清晰、竖版 1080×1920。
5. **发布包**：视频 + 标题 + 描述（含 @念念AI社，相关时 @念念制片厂）+ 封面 + 时段建议（11:30–13:00 或 20:00–22:00）。

## 最小变现产品（对齐战略文档）

真实商品资料审计 + 1 条 15–30 秒商品视频 + 1 次明确范围内修改 + 一页内容复盘。承接试单时按此报价，不夸大。

## 红线

- 不虚构销量、转化率、功效、客户评价。
- 不用生成图冒充真实商品效果。
- 每条记录真实制作成本、工时、修改次数，供复盘。
