## 1. 一句话定位 v2

> **天庭高官的受宠女儿，第一次偷跑进凡间；她不知道自己会落在哪里，却被偶然撞见的山河、风和烟火吸引，慢慢拍成了自己的旅行 vlog。**

基调：轻喜剧 + 自由向往 + 人间温度。
形态：写实架空。人间真实，天宫与仙女架空。

---

## 2. 世界观规则 v2（定死不改）

1. **天庭=高压职场+世家**。念念之父为天庭高官（虚构职衔：云台真君·巡天使首座）。她对念念的爱是真的，“安排好一切”也是真的——念念逃的是“被安排”，不是家。
2. **第一次下凡=完全未知的偷跑**。念念第一次穿过天门时，仙界没人知道她离开；她自己也不知道凡间是什么、会落在哪里。她不是带着目的地出发，而是随便闯出去，偶然落在福建一带。首集先用第三人称表现她从储物法宝袋里掏出凡间物件、试用拍摄设备，再通过开机转场进入第一人称；前期不追捕、不解释、不抢旅行内容。
3. **法力全开**。能飞、能遁、能使用小法术。被凡人看到不回避——架空就架空到底；但念念不会主动向凡人介绍自己的身份。
4. **人间主体真实**。风景、人文、烟火用真实素材；凡人跟她互动时，只把她当成一个漂亮、奇怪、会飞的旅行者，真相慢慢留到后面。
5. **神职体系全虚构**，不借真实宗教人物与叙事。
6. **账号称呼自然形成**。念念在前期只是记录和分享眼前发生的事；“家人们”可以逐步成为她的口头称呼，不作为第一次下凡时的硬性设定介绍。

## 4. 内容形态 v2

- 长线连续剧原则：旅行不是三集讲完一个事件，而是让念念在一个个具体日子里慢慢生活、拍摄和认识凡间；每集只推进一个小目标，人物关系、时间流速、身份真相和父女线全部后置。
- 慢节奏不等于低能量：念念的口播可以明亮、快速、有即时反应，但镜头要保留走路、观察、试吃、失败、环境声和停顿。
- 视觉比例：**人间 50% / 仿真人 30% / 天宫 20%**。
- 人间以**第一人称 POV（念念手持拍摄设备）**为主；仿真人出现在自拍机位、飞行第三人称大远景、手部/倒影；天宫用于开场/转场/后续剧情线。设备只服务于镜头效果，不在前期口播中专门介绍。
- 口播=vlog 语气，第一次下凡不使用“我又偷跑出来了”“福建见”等熟悉凡间或账号化表达；她先对眼前的新鲜事做即时反应。后续账号稳定后再自然形成“家人们”等亲近称呼，不要求机械重复；固定收尾根据内容自然收束，不强行使用口号。
- 三支柱：旅行 vlog（主体）/ 天庭日常（日更低成本填充）/ 故事特辑（父女线、人间真善美、时事温暖回应）。爱情线不作为栏目推进，长期藏在动作、错过、沉默和未说出口的话里。
- 时事红线不变：只碰温暖/庆祝/文化类，不碰争议对立。

## 5. 上中下三集结构（立人设，每集 3:00–3:30）

生产拆分沿用漫剧产线：每集约 6–7 段 × 30s + 尾段。以下为节拍表。

### 上集《家人们，我刚刚落到一个地方》（约 3:20）

| 时间 | 节拍 |
|---|---|
| 00:00–00:30 | 天宫晨间：爹宣布日程，念念表面乖，手上已经开始收拾要带走的东西 |
| 00:30–01:00 | 偷跑：她从偏门离开，没人发现；穿过云层时还不知道自己要去哪儿 |
| 01:00–01:30 | 第一次看见凡间：远处山海和灯火突然铺开，她被眼前景象吸引，随机落到福建一带 |
| 01:30–02:10 | 她第一次逛海边、看街巷、吃东西；先拍到什么就说什么，不报景点、不讲背景 |
| 02:10–02:50 | 她第一次遇见凡人和手机镜头，觉得新鲜，短暂飞起又落下；没有身份解释 |
| 02:50–03:20 | 她找地方继续拍，天黑了也不急着走；念念开始觉得凡间比想象中有意思 |
| 尾段 | 片名落版；不预告大剧情，只留下“她明天还会去哪儿” |

### 中集《家人们，这里的人怎么这么会吃》（约 3:10）

| 时间 | 节拍 |
|---|---|
| 00:00–00:40 | 念念在福建街边醒来，第一次自己找吃的、找路；对各种凡间东西一边好奇一边乱试 |
| 00:40–01:20 | 她拍早市、海边、古厝、茶摊；镜头跟着她看到什么拍什么，不做景点介绍 |
| 01:20–02:00 | 第一次和凡人自然互动：买东西、问路、学一个小动作；念念因为沟通方式和生活习惯闹出小笑话 |
| 02:00–02:40 | 她发现拍下来的画面比自己想象中有意思，开始认真记录；“家人们”在分享过程中自然出现，不解释账号设定 |
| 02:40–03:10 | 她看见新的海岸或灯火，立刻改路线继续走；只留下“明天再拍”的轻钩子 |

### 下集《家人们，先把今天拍完》（约 3:30）

| 时间 | 节拍 |
|---|---|
| 00:00–00:40 | 念念已经有一点自己的旅行节奏：早起、找吃的、拍风景；但仍然会被新东西吸引，临时改行程 |
| 00:40–01:20 | 福建山海、街巷、茶园、渔港连续展开；以第一人称内容为主，仿真人只在必要处出镜 |
| 01:20–02:00 | 她第一次认真尝试飞过山海拍摄，凡人远远看见；念念只觉得新鲜，不解释身份、不制造热搜 |
| 02:00–02:40 | 她看到天色变暗，想起自己似乎出来有一阵了；犹豫一下，还是先把眼前这段拍完 |
| 02:40–03:20 | 她收设备准备离开，又被一处新风景留下；嘴上说“最后一个”，动作却已经往前走 |
| 尾段 | 片名落版；不回天庭、不揭时间差、不推进追捕和爱情线 |

三集完成后，账号继续以旅行 vlog 为主体，逐步穿插天宫日常和故事特辑。
