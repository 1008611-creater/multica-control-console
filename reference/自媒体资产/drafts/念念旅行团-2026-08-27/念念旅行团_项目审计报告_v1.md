# 念念旅行团｜项目审计报告 v1

日期：2026-08-27
审计范围：世界观设定资产库、IP方案、首发三集人设稿、一日分镜执行卡、视频生成提示词包、Vlog声音规范。

## 一、结论

项目方向成立，核心差异清楚：写实福建/国内旅行内容 + 3D仿真人念念 + 中式架空天宫。

当前主要问题不是创意不足，而是：

1. 资料版本出现冲突，缺少唯一总稿；
2. “每集3分钟至3分半”与当前逐镜时长不匹配；
3. 首次下凡的关键生活逻辑还没有补齐；
4. 真实福建素材、3D人物和第一人称镜头的生产标准还不够具体；
5. 账号从“念念私自拍摄”变成“观众能看到的Vlog”的世界内机制未锁定。

## 二、一级问题：必须先处理

### 1. 版本冲突，后续很容易写乱

`念念旅行团_IP世界观方案_v2.md` 仍有旧节奏内容：上集包含夜景，中集像第二天早晨，下集写成已经形成旅行习惯；而 `念念旅行团_首发三集人设引入版_v3.md` 和一日分镜卡已经锁定为同一天的上午、中午、下午至晚上。

处理建议：

- 将 v3 人设稿、一日分镜执行卡、视频提示词包定为当前生产主线；
- v2 方案改成“历史版本/只保留长期世界观”，删除旧三集节拍；
- 后续所有脚本只引用一个“当前总控稿”。

### 2. 单集时长与镜头时长对不上

当前详细分镜大致为：

- 上集约90秒；
- 中集约105秒；
- 下集约108秒。

但项目规格是每集3:00–3:30。即使加环境声和停顿，也不够稳定地撑满三分钟；另一方面，提示词包又按5–15秒一镜，粗剪后可能超过目标时长。

必须先选一个生产口径：

- A：保留3:00–3:30，每集增加完整过程、空镜、环境声、人物反应和连续动作；
- B：首发三集先做90–120秒，后续长线再升级到3分钟；
- C：每集3分钟，但按“素材时长”和“最终剪辑时长”分开统计。

建议选 C。现在的分镜时长应视为“剧情动作时长”，不是最终成片时长。

### 3. 首次下凡的“钱、吃饭、语言”逻辑缺口

中集让念念点餐、加菜、付款，但当前版本出现了“用法力变出纸钞”的处理。她第一次接触凡间，不应突然熟悉货币，也不建议让法力凭空制造现实货币。

还缺三个基础规则：

- 天界与凡间是否自然互通语言；
- 念念身上有没有从父亲那里顺来的少量凡间零钱；
- 第一顿饭是正常付钱、被摊主请，还是用随身物件交换。

建议：语言默认互通；法宝袋里有父亲留下的少量零钱，但念念不知道怎么用；付款过程只拍成一个小麻烦，不解释制度。

### 4. 首次落地地点太宽，福建素材可能互相穿帮

当前同时使用海边、滩涂、古厝、街巷、茶园、渔船和夜市，但“福建”不是一个单一场景。若这些素材来自不同地区，同一天内会出现地貌、建筑、交通距离和光线不连续的问题。

建议先确定一个首发微区域：

- 具体落地地貌；
- 海边到街巷的移动方式；
- 街巷到夜市的空间关系；
- 哪些福建素材属于同一日，哪些只能作为后续旅行。

念念会飞可以解决距离，但不能拿来掩盖所有剪辑跳跃；飞行也应成为内容动作，而不是万能转场。

## 三、二级问题：不马上修会影响后续

### 5. “为什么偷跑”目前有动作，没有触发点

她回头看门、打开法宝袋，观众能看出她在偷偷摸摸，但还不知道她刚刚躲开什么。

不需要长篇解释，只要在开头增加一个很短的可视触发：正式衣物、礼仪器物、远处传来的父亲声音、悬浮的日程文书等。让观众看到“她刚被安排过，所以现在想溜”，不要靠台词说明。

### 6. “记录”与“发布”没有世界内机制

现在她拿设备拍摄很自然，但项目又是自媒体账号。需要后续明确：

- 前三集是私人记录，还是已经能被观众看到；
- 她什么时候第一次发布；
- 凡间网络如何接入；
- 她是否知道自己有观众；
- “家人们”从第一天就能说，还是账号成形后才出现。

建议前三集先定义为“她在记录，观众以作品形式看到”；不要急着在剧情里解释发布机制。长线再安排一次自然的公开契机。

### 7. “法力全开”与“第一人称拍摄”需要镜头规则

她会飞、能施法，但手里又拿着设备。生产时要统一：

- 飞行时设备如何固定；
- 是手持、悬浮跟拍，还是法力控制；
- 第一人称是否偶尔看见手、衣袖、影子；
- 设备画面和第三人称仿真人画面的镜头高度是否一致。

否则会出现“人物在飞，摄影机却像无人机”的视角错乱。

### 8. 真实品牌和潮玩存在版权、广告感和生成稳定性风险

牛来、奶龙、可口可乐、DJI/Osmo 等都可能涉及商标、版权或商业使用问题。AI生成还容易出现错误Logo、变形包装和疑似广告展示。

建议把物件分三级：

- 已有授权/自有素材：可清晰出现；
- 仅作剧情道具：弱化Logo，不做产品特写；
- 未确认授权：改成原创相似功能物件。

品牌型号也不要在主设定里过早锁死，生产前以官方存在、可获取素材和使用权限为准。

### 9. “人间50%/仿真人30%/天宫20%”需要明确统计口径

如果这是每集比例，首集法宝袋和天宫段会超出20%；如果是整个账号或第一季比例，就没有问题。

建议锁成“账号/阶段平均比例”，不要要求每一集机械达标。单集应该服从内容：第一次下凡的首集可以天宫稍多，纯旅行Vlog可以人间明显更高。

### 10. 念念的年龄与独立生活能力未锁定

当前有“年轻女生”“天庭大小姐”“未来暗恋线”，但年龄和仙龄未定。她独自在人间旅行、消费、住宿，后续还要发展爱情线，最好明确为成年角色，并锁定外貌年龄、仙龄、身体成长和寿命规则。

这不是为了在前三集讲出来，而是为了避免后续人设和情感尺度漂移。

## 四、三级问题：可在首发后优化

### 11. 首发三集的持续观看钩子还偏弱

现在结尾主要是“再看一会儿”“继续走”“夜市入口”。慢节奏没有问题，但每集仍需有一个小的未完成动作：

- 上集：她刚发现凡人也在拍她；
- 中集：她发现自己不会付钱/不会回到刚才的摊位；
- 下集：她第一次要面对凡间夜晚，但先被香味吸引。

钩子要是内容上的下一步，不要变成抓捕、热搜或身份曝光。

### 12. 真实人物拍摄规范还不完整

已有“不要虚构真人故事”的原则，但还需要补：

- 可识别脸部是否经过授权；
- 路人声音是否保留；
- 摊主、老人、儿童是否能直接入镜；
- 真实地点是否允许商业发布；
- 真实素材和AI合成画面如何标注。

尤其是“人间温暖故事”栏目，不能只靠“不编故事”一句原则，需要建立素材授权和事实核验清单。

### 13. 3D人物与实景融合标准还没有角色资产包

目前只有“年轻清丽、浅色仙裙”等概念描述，还缺生产级固定项：

- 脸型、发型、发色、眼睛和妆面；
- 仙裙主色与备用服装；
- 身高比例和手部特征；
- 法宝袋、设备、旅行包的固定外观；
- 适用于正面、侧面、背面、手部和倒影的参考图。

如果先生成视频再补角色资产，连续剧很容易出现“每集换一个念念”。

### 14. 声音规范方向正确，但还缺配音母版

现有规范已经避免了具体创作者的直接模仿，这是对的。下一步要把它落成：

- 语速区间；
- 兴奋、好奇、尴尬、专注、困惑五种情绪样例；
- 同一句台词的轻声/高能两版；
- 口播与环境声的混音优先级。

否则“有网感”仍会因配音演员不同而漂移。

### 15. 天宫和父亲的长期戏剧功能还没完全分开

父亲目前同时承担高官、宠女、控制欲、未来追查和情感线源头；天宫又同时承担职场喜剧、宏大视觉和时间差背景。后续需要区分：

- 父亲线：家庭关系；
- 天宫线：制度和职场日常；
- 念念旅行线：主内容；
- 闻川线：长期暗恋，不抢旅行主线。

否则父亲一出现就会把旅行内容拉成家庭连续剧。

## 五、当前建议锁定的生产优先级

### P0：先处理

1. 选定唯一总稿，清理 v2 旧三集结构；
2. 确认每集最终成片时长统计方式；
3. 确定首发福建微区域和素材连续性；
4. 补齐第一顿饭的语言、零钱和付款逻辑；
5. 暂不把 Pocket 4 和具体品牌展示写死，生产前核对型号与使用权限。

### P1：随后处理

1. 建立念念角色资产包；
2. 建立第一人称镜头规则；
3. 建立真实人物/地点素材授权规则；
4. 明确私人记录到公开Vlog的自然转折；
5. 明确成年、仙龄、寿命和人间生活能力。

### P2：首发后慢慢补

1. 天宫职场栏目结构；
2. 父女线触发顺序；
3. 闻川暗恋伏笔库；
4. 人间热点使用流程；
5. 世界篇的真实素材与AI生成边界。

## 六、审计总判断

这个项目可以继续做，且不需要推翻重来。

真正要守住的不是“设定越多越好”，而是三条生产纪律：

1. **当前一天先拍完整，长线设定先不抢戏；**
2. **所有设定必须服务内容，不用解释替代发生；**
3. **所有版本只保留一个当前执行口径。**

首发三集下一轮不建议继续扩写世界观，建议先做“总稿清理 + 福建素材地图 + 时长重算 + 首集角色资产需求表”。
