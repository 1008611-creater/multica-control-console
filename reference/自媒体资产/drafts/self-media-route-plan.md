# 自媒体 Skill 完整路线

本路线把一个真实项目、文章、视频、截图或产品结果，转成可以人工审核、逐平台适配、最后再决定是否发布的内容生产闭环。

## 总路线

```text
真实项目/素材
  -> 来源盘点与证据登记
  -> 受众问题与外部研究
  -> 真实价值提炼与内容角度
  -> 小红书图文方案
  -> 抖音口播与短视频方案
  -> 9:16 封面和素材包装
  -> 敏感词、事实和夸大检查
  -> 本地工作台生成草稿
  -> 人工审核与账号授权
  -> 平台草稿/发布
  -> 数据回读与下一轮迭代
```

当前默认状态：只做到本地草稿；不登录、不读取凭证、不自动发布。任何外部平台写入都必须由用户在明确的发布步骤中授权。

## 阶段安排

| 阶段 | 输入 | 主责 Skill/工具 | 产出 | 完成标准 |
|---|---|---|---|---|
| 0. 接收与定界 | 项目目录、文章、视频、截图、产品说明 | 自媒体 Skill 路由 | 来源包、目标平台、边界 | 来源可定位，明确“不编造、不发布”约束 |
| 1. 证据盘点 | 项目文件、真实页面、测试结果 | 项目读取 + 证据清单 | 事实证据表、不可公开内容表 | 每条事实有来源和表述边界 |
| 2. 研究受众 | 公开网页、平台公开内容、用户问题 | Agent-Reach；中文素材时再用 chubbyskills | 痛点、竞品、关键词、选题依据 | 外部事实与项目自身事实分开 |
| 3. 价值提炼 | 证据表、用户痛点 | 自媒体 Skill 路由 | 一句话价值、目标人群、内容角度、证据链 | 价值来自真实结果，不用流量或收益猜测替代 |
| 4. 小红书图文 | 内容角度、真实截图 | xhs-note-creator + xhs-traffic-aesthetic-guard | 8 页卡片、标题、正文、标签、评论引导 | 首屏清楚，图片尺寸稳定，截图保真 |
| 5. 抖音视频 | 内容角度、真实截图/视频 | social-video-planner-skill | 30 秒口播、分镜、字幕、节奏 | 前 3 秒说明痛点，事实边界和画面一一对应 |
| 6. 视觉包装 | 8 页内容、口播方案、真实素材 | visual-director-skill | 9:16 封面、卡片视觉规则、素材清单 | 真实产品画面优先，不用生成图冒充结果 |
| 7. 视频制作 | 口播、素材、字幕、配音需求 | ClipForge；需要时再接媒体工具 | 视频草稿、多平台导出包 | 本地页面/构建通过，成片可回读 |

| 9. 工作台归档 | 所有草稿和检查结果 | AiToEarn（按需启动） | 可视化内容、日历、草稿记录 | 启动后真实页面可访问，用完关停 |
| 10. 人工确认 | 完整草稿、检查报告 | 用户本人 | 登录/保存草稿/发布决定 | 账号、扫码、验证码和最终发布由用户控制 |
| 11. 平台执行 | 已确认草稿、已授权账号 | 小红书工具、抖音上传工具或 AiToEarn | 平台草稿或已发布内容 | 只有明确授权后才写入外部平台 |
| 12. 数据复盘 | 真实作品数据、发布时间 | douyin-mcp 等平台数据工具 | 数据快照、有效因素、下一轮改稿 | 每个结论有作品和时间依据，缺失数据明确标记 |

## 文件和写入约定

每个项目使用一个批次目录，例如：

```text
self-media-drafts/<project>-<date>/
  00-source-inventory.md
  01-research-brief.md
  02-value-angle.md
  03-xiaohongshu-8-pages.md
  04-douyin-30s.md
  05-cover-9x16.md
  06-compliance-check.md
  07-review-notes.md
  assets/
  rendered/
```

每一阶段只写自己的文件，不覆盖上一阶段的事实证据。真实截图放在 `assets/`，渲染结果放在 `rendered/`，账号凭证永远不进入批次目录。

## 当前质量门

1. 事实必须能回到项目文件、真实页面、测试结果或用户提供的材料。
2. 截图中的界面文案不自动变成对外承诺。
3. 本地构建、健康检查和 Skill 文件存在，只能报告为“已部署/已构建/离线试跑通过”。
4. 没有登录态时，平台能力只能报告为“待登录”，不能报告为“已发布验证”。
5. 敏感词检查只能减少表达风险，不能替代人工确认和平台审核。
6. 生成草稿、打开本地网页和提交 Provider 任务都不等于真实发布。
7. AiToEarn 默认关停；需要时启动，验证或使用结束后停止。
